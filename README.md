# Library Management System

A simple **Library Management System** built using **C# and .NET**. The program allows users to display, add, and remove books from a library using a generic list. Each book contains details such as its name, description, author, price, and quantity available.

## 🚀 Features

- ✅ Displays all books available in the library
- ✅ Allows users to add new books
- ✅ Allows users to remove books using their index
- ✅ Stores book details such as name, description, author, price, and quantity
- ✅ Includes three initial sample books
- ✅ Uses a menu-driven console interface
- ✅ Uses a generic `List<Book>` to manage book objects
- ✅ Displays book details using an overridden `ToString()` method

---

## 🎮 Application Menu

The application provides the following options:

| **Option** | **Action** |
| ---------- | ---------- |
| 1 | Display Books |
| 2 | Add Book |
| 3 | Remove Book |
| 4 | Exit |
